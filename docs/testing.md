# 测试指南

本仓库**没有自动化测试**：`src/test` 不存在，`build.gradle` 未注册任何回归任务，`gradlew test` 只是空跑默认任务。质量靠编译检查 + 手测清单保证；改完代码至少跑一次 `.\gradlew.bat compileJava`。

## 手测清单

发版或大改动前，在创造模式大基地地图上至少覆盖：

1. **加载与设置**
   - 模组正常加载，`设置 → 模组 → 电网小地图` 打开且各分组完整。
   - 改动 颜色 / 透明度 / 字号 等设置后立即生效，重进游戏后保留。
2. **HUD 小地图**：每个电网被不同颜色覆盖，电网中心出现 `+/-` 盈亏数字；缩放小地图时数字跟随（受"随小地图缩放"设置影响）。
3. **全屏地图（按 `M`）**：分色叠加 + 盈亏标记正确，与 HUD 小地图一致。
4. **断网告警（SplitAlert）**：剪断大电网的一条供电线，数秒内弹出告警并出现建议重连点与连线；恢复连接后告警消失。
5. **缺电救援建议（RescueAdvisor，默认关）**：制造持续负电电网，开启后确认 正电岛圈注 / 冲击反应堆标记 出现，关闭后消失。
6. **电力表（PowerTableOverlay，默认关）**：开启后 HUD 出现大电网列表；装 MindustryX 时以 OverlayUI 窗口呈现（可拖动/固定），无 MDtX 时回退普通 HUD。
7. **MI2U 集成（默认关）**：安装 MI2-Utilities 后开启"绘制在 MI2 小地图上"，用非正方形地图验证叠加对齐（历史 bug 高发区）。
8. **联机兼容标记（默认关）**：两人联机，触发断网告警时确认聊天中出现 `<PGMM>(x,y)` 标记且频率受间隔设置限制。
9. **客户端指令与控制台**：`/pgmm-restart`、`/pgmm-rescan`、`/pgmm-mi2` 均有响应；F8 控制台 `pgmm.help()` 列出全部 API。
10. **安卓包**：安装 `deploy` 产出的合并 jar（含 `classes.dex`）可加载，核心功能可用。

## Neon 聚合态

并入 Neon 打包（`bekBundled = true`）时额外确认：PGMM 不再注册独立设置分类，其设置分组出现在 Neon 总设置页中且功能正常。
