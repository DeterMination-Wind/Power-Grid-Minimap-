# Detail: src

## 这一层在做什么
src 是项目源码总入口层，所有应被视为“源”的内容都从这里开始。

## 这一层直接包含什么
### 直接子目录
- main

### 直接文件
- 本层没有直接文件，职责主要体现在子目录与其生成关系上。

## 这一层如何实现自己的职责
当前只有 main，没有 test 或 android 等额外源码集，说明 PGMM 结构紧凑、测试体系缺席、平台差异主要通过构建脚本解决。

## 这一层与其他层级的关系
它向下分为 java 与 resources，向上被 build.gradle 当作 sourceSets.main 的主体输入。

## 阅读这一层时要注意什么
这层越干净，越说明仓库把源和派生物分得清楚。
